# 六张方向卡

秒数轮盘：S=32 → 网页分区 32%20+1=13「Linear 暗色发光 Bento」——深色，与“浅色”需求和外观账本（最近两次都是深·近黑底）冲突，按规则顺延到 14「斜切流体渐变带」；东亚分区 32%12+1=9「田中一光几何平面构成」。

现实参照的两件作品本会话无法截图（npm 代理不可用、无 python playwright），卡上标注「未亲眼看到」，规则来自对作品的长期使用记忆。

---

## C1 · 最佳设计师 · Otl Aicher（乌尔姆 / ERCO / 慕尼黑奥运视觉系统）
- 借的是什么：颜色即信息分类——每种区域类型一种信号色，全软件统一（考号=钴蓝、客观题=绿、主观题=橙、条码=紫、定位=墨黑、异常=朱红）；严格模块网格（8px 基准）；象形方块图标；冷灰机箱 + 白色工作面
- 主角素材：答题卡画布 + 彩色区域叠层，扫描页里的缩略图同样带彩色识别叠层
- 骨架：左侧 64px 图标栏 + 三栏工作台（列表 / 主画面 / 检查器），底部状态条
- 胆量花在哪：区域色码贯穿所有页面，计数、图例、列表标记都用同一套颜色，一眼对应
- form 来自内容的哪里：答题卡本来就是“分区”的——考号区、客观题区、主观题区，颜色系统就是这张卡的分区图

## C2 · 最佳设计师 · 深泽直人（无意识设计 / 纸面工具）
- 借的是什么：界面借答题卡自己的印刷语言——发丝黑线框、`[A]` 方括号标签、宋体标题；冷白纸面 #F6F6F3、墨黑；铅笔石墨灰作主强调，校对红只给物理异常
- 主角素材：同步头黑块——扫描进度条就是一排同步头，每张纸一个黑块，异常的那块是红色
- 骨架：顶部细工具条 + 中央大幅当前卡预览 + 右侧窄“账页”（计数与待处理），像一张摊开的考务登记表
- 胆量花在哪：进度条＝同步头
- form 来自内容的哪里：同步头、方括号选项、细线表格都是答题卡本身的字形

## C3 · 现实参照 · Figma UI3（浅色）〔未亲眼看到〕
- 借的是什么：左图层树 / 中画布 / 右属性分节；画布底部悬浮工具条；蓝色 #0D99FF 选中态；属性面板 12px 标签 + 14px 值的密排
- 主角素材：画布
- 骨架：编辑器式三栏，扫描页也用“画布 + 属性”结构（画布显示当前卡，右侧是参数与计数）
- 胆量花在哪：底部悬浮工具条
- form 来自内容的哪里：模板编辑就是在卡上画框——最接近设计工具

## C4 · 现实参照 · macOS 照片 / 图像捕捉（浅色）〔未亲眼看到〕
- 借的是什么：灰色源列表侧栏、大缩略图网格、分段控件、右侧检查器
- 主角素材：扫描缩略图网格（实时流）
- 骨架：侧栏 + 缩略图墙 + 检查器
- 胆量花在哪：缩略图墙占满主区，异常卡直接在墙上标红
- form 来自内容的哪里：扫描本质是“一叠图像在流动”

## C5 · 秒数轮盘 · 网页 14 斜切流体渐变带（Stripe）
- 借的是什么：靛蓝 #635BFF → 青 → 粉的渐变只出现在顶部一条斜切色带（扫描进行中时它就是“机器在跑”的状态带）；纯白内容区；近黑文字；理性栅格压表达渐变
- 主角素材：渐变状态带 + 大号计数
- 骨架：顶部渐变带（大计数）+ 下方两栏（缩略图流 / 待处理）
- 胆量花在哪：渐变带
- form 来自内容的哪里：较弱——渐变只表达“运行中”，与答题卡本身关系不大
- 还原度：Qt 可做线性渐变，斜切边用 QPainterPath，约 85%

## C6 · 秒数轮盘 · 东亚 9 田中一光几何平面构成
- 借的是什么：红 #D9381E / 黑 / 芥黄 #E3B23C / 钢蓝 #3D6E8F 四色平涂；方、圆、四分之一圆作为状态符号（■ 成功、● 物理异常、◖ 数据警告、▲ OCR）；粗宋标题；小红标签分块信息；底部细黑线
- 主角素材：几何状态符号构成的计数区（每张卡一个几何格，拼成一幅构成图）
- 骨架：左宽信息栏（竖排粗宋考试名 + 红标签信息块）+ 右主区
- 胆量花在哪：批次进度＝几何格拼图
- form 来自内容的哪里：涂卡本身就是“在网格上把方块涂黑”
- 还原度：纯色平涂与几何形 Qt 完全可做；竖排标题用逐字布局，约 90%
