# 设计 spec · 答题卡扫描识别（scan-answer）桌面端

## 项目是什么
连接 A3 高速双面扫描仪（Windows/TWAIN），按模板批量识别答题卡：考号填涂、条码、缺考、客观题（OMR）、主观题切图、可选的大模型手写转写，输出 JSON + 图片。不做批改。macOS 上无扫描仪，入口为“导入图片”。

## 受众与场景
- 扫描员（考务老师/教务）：站在扫描仪旁，一边放纸一边看屏幕，眼睛在纸和屏幕间来回 → 计数和异常要远距离一眼可读
- 模板制作者（懂考务的老师/实施人员）：坐着精细框选，长时间操作画布 → 画布最大化、属性面板密而清楚
- 一天可能扫几千张，持续数小时：长时间盯屏不累眼

## 核心信息（按重要度）
1. 现在扫到哪了、有没有出问题（物理异常要立刻处理：重扫/作废）
2. 识别结果可信吗（数据警告只标记，不拦截）
3. 模板的每个区域框得准不准

## 情感基调
可靠、冷静、像一台精密仪器；不是营销页，不炫。浅色主题（用户指定）。

## 输出格式与尺寸（三版统一）
- 单文件 HTML，窗口 1440×900，模拟桌面应用窗口（无浏览器外壳）
- 每个方向至少完整做出：**扫描主界面** + **模板编辑器**；首页/结果浏览/设置做成可切换的真实页面（内容可简于前两者）
- 左侧/顶部导航真能切换页面

## 已知约束
- 最终用 PySide6 + QSS 实现：不用 backdrop-filter 毛玻璃、复杂混合模式、视差、依赖 Web 独有的特效；渐变、圆角、阴影、细线可以
- 中文为主，正文 ≥14px，标签 ≥12px，对比度 ≥4.5:1
- 字体：Windows 微软雅黑 / macOS 苹方，原型用 `-apple-system, "PingFang SC", "Microsoft YaHei"`；数字可用等宽数字（tabular-nums）

## 真实内容（三版同内容）
- 考试：2026 年全国硕士研究生招生考试 · 管理类综合能力（199）· 第一考点 · 操作员 李老师
