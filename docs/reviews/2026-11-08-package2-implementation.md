## 审查中发现并补上的问题

1. 新模板初始版本 0 与正式版本校验冲突。对草稿使用首次保存的候选版本进行校验，文档本身仍保留 0，直到成功发布。
2. 撤销题号修改后，追加目标仍保存新题号，导致跨面画框误建新题。恢复历史时同步恢复同一道题的追加目标。
3. 修改被校验拒绝之前就写入撤销点，会丢失原有重做记录。改为成功修改且内容修订号变化后，再提交修改前快照。
4. 给现有题目追加越界矩形时，数据层拒绝但界面未处理异常。现在显示原因、退出画框工具，保留文档和重做记录。
5. 可读取但结构无效的外部旧模板（例如 DPI 为 0）仍能被固定到考试。考试创建和迁移现在都在发布快照前进行结构校验，失败不改变旧考试、不留下可选的半成品。

新增回归先观察失败，再验证修复，未用放宽断言替代修复。

## 尚未由本包验收的项目

- Windows TWAIN 扫描仪的纸张能力、单双面、卡纸 / 双张、暂停停止与设备释放。
- 真机上的 A3、8K、A4 / A5 及更多尺寸实扫；当前尺寸约束和模拟卡测试不能替代设备验证。
- 采集中断、半份答卷恢复、重扫替换、OCR 重试代次和退出管理等后续主线流程。
- 最终交付检查、完整目录搬移、坏图与缺图的统一阻断，以及性能和分发包验收。
- 没有重建 `.app` 或 Windows 安装包；已安装版本不会自动包含本轮源码改动。

底图资源采用不可变文件，失败保存可能留下未被当前 JSON 引用的完整资源；本包未增加自动垃圾回收，以免删除仍被旧版本引用的证据。试识别仍使用现有后台线程方式：修改后丢弃过期结果，不保证立即中断已经开始的识别计算。
