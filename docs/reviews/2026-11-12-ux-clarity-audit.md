# 界面“看不懂”问题排查（2026-11-12）

范围：考试、扫描、模板（列表 + 编辑器 + 新建对话框 + 试识别）、结果（核对答卷 + 交付）、设置五个页面，加上主窗口（侧栏、顶栏、状态栏、F1 使用说明）、手动定位对话框、扫描异常卡上的操作和确认框。文字来源核对了 `src/scan_answer/ui/help_text.py`、代码里的悬停说明、`docs/gui.md`。

方法：逐个读页面代码；另外在沙盒 HOME 里用 offscreen 脚本（改自 `/tmp/sa-shot/inventory.py`，加了模板页）列出了全部按钮、菜单项、下拉选项、快捷键和“?”，和读代码得到的清单对过一遍。评判角度是**第一次用的普通老师**：只看按钮名字和位置，鼠标悬停时能看到提示。

已经修好的两处（“添加区域”工具列、主观题的“画到”）不再列入。已经清楚的控件也不列（例如“新建考试”“创建并进入扫描”“保存模板”“检查交付”“生成交付目录…”“测试连接”，以及作废确认、已结束批次再导入的二选一对话框）。只提名字、说明文字、摆放位置、操作反馈和分组方面的修改，不提新功能，也不改业务逻辑。

类别：A 名称看不出作用｜B 术语太专业｜C 相关的东西分开放｜D 入口太隐蔽｜E 不能点却不说为什么 / 点了没反馈｜F 容易误操作或后果不明｜G 同一件事叫法不一致

严重度：**高**＝用户可能卡住或用错；**中**＝要猜一下才懂；**低**＝措辞可以更好

总体判断：每个按钮的悬停说明大多写得认真，被禁用时也会说明原因。剩下的问题主要有三类：

1. **按钮名用的是开发时的叫法**，比如“结束本轮”“确认无误”“重新结算”“补做和重试转写”“新批次”“运行”。不悬停就猜不出点了会怎样。
2. **同一个概念在各页叫法不同**，比如“物理异常 / 异常 / 异常卡”“数据警告 / 有警告 / 警告”“结算 / 已结算 / 已结束 / 结束批次”“定位块 / 定位点 / 参照点”“未启用 / 未开启 / 已放弃”。
3. **算法用语直接显示给老师**，比如“阈值”“涂黑度”“仿射”“叠层”“证据”“WRONG_CARD”“进程”“并发”。
