## 实现范围

- 默认跟随 Qt 报告的系统外观；使用 `QStyleHints.colorSchemeChanged`
  在 GUI 事件循环中刷新，不修改操作系统外观设置。
- 浅色保留原有冷灰和白色工作区；深色采用中性深灰背景、浅色文字，
  并适配告警、错误、选中、禁用、焦点、占位提示和主按钮颜色。
- 通过统一 QPalette、全局样式、保留语义颜色的局部样式，更新已经创建的
  表单、表格、树、列表、页签、菜单、对话框和 JSON 预览。
- 已有表格/树节点的颜色原位更新，不重建模型；更新时阻止数据修改信号，
  避免外观变化触发文档编辑或选中项改变。
- 导航图标、统计数字、扫描状态、设备提示、识别告警和模板树文字同步刷新。
- 模板未保存修改、撤销/重做、表单输入、选中答卷、图片像素和画布缩放保持。
- 纸面图像不反色，图片证据与区域标记颜色不随应用背景改变。
- 截图发现的两个较窄窗口问题已修正：设置页改用可滚动表单；扫描预览宽度
  可缩小，避免与右侧识别信息重叠。

## 边界

- 当前主机是 macOS。Windows 控件样式验证不等同于实际 Windows 系统验收；
  Windows 的系统外观通知、标题栏及原生文件选择器仍需实机确认。
- macOS 已验证原生启动偏好及 Qt 原生配色通知路径，但没有更改用户系统
  设置来模拟系统设置应用中的点击操作。
- 这轮只调整界面及对应验证，没有改动识别算法、扫描驱动或结果输出格式。
- 未调用付费 OCR，未重新打包应用。
- 当前没有可用的 JetBrains MCP 检查工具，使用 pytest、Qt 原生运行检查、
  Ruff F 和 `git diff --check` 验证。
