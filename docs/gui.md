# 图形界面使用说明（第 1 期）

启动：`scan-answer-gui`（开发环境：`.venv/bin/scan-answer-gui`）。

使用 uv 时，在项目根目录运行 `uv run scan-answer-gui`，或
`uv run python -m scan_answer.ui.app`。也支持直接运行或 Debug
`src/scan_answer/ui/app.py`。IDE 解释器应选择项目的 `.venv/bin/python`
（Windows 为 `.venv\Scripts\python.exe`），工作目录设为项目根目录；
首次准备环境先运行 `uv sync --extra dev`。

命令行入口是 `src/scan_answer/cli.py`，支持
`uv run python src/scan_answer/cli.py --help`、`uv run python -m scan_answer.cli --help`
和 `uv run scan-answer --help`。直接 Debug 此文件时，在运行配置中填写
`--help` 或实际子命令参数；CLI 不带参数会提示缺少必需的子命令，不会打开图形界面。

## 系统深浅主题

界面默认跟随 macOS / Windows 的系统外观，启动时读取深色或浅色偏好，
运行中收到外观变化通知后自动更新，无需重启或重新打开当前考试。
系统未报告外观偏好时，以原生控件样式的默认调色板作为回退。

考试、扫描、模板、结果、设置页，以及已打开的对话框、输入框、表格、
下拉列表和 JSON 预览共同更新。切换只改变显示颜色，不重新载入数据，
保留模板未保存修改、撤销记录、选中答卷、表单输入、缩放及滚动位置。
设置页分节显示，每节内容较长时可滚动；扫描预览在较窄窗口内缩小以保留识别信息的位置。

答题卡和题目图片不反色、不改变灰度，纸面区域标记保持原来的颜色。
正在运行的旧程序需要先关闭并从更新后的源码启动一次；旧安装包不会自动
获得这些改动。

## 界面内说明

- 鼠标停在左侧页面按钮（考试、扫描、模板、结果、设置）上，显示这一页做什么、按什么顺序操作。
- 按钮、输入框等控件悬停有说明；按钮不能点时，悬停说明原因和该先做什么。
- 难懂的概念旁有“?”，悬停或点击显示解释（批次、结束本轮 / 结束批次、吸附、试识别、标识区、忽略区、交付检查等）。
- 列表为空时显示下一步怎么做；扫描页、结果页、模板编辑器的提示行会随进度提示下一步。
- 按 F1 或点状态栏“使用说明（F1）”打开使用说明：整体流程、各页功能、模板区域和容易混的词。

## 典型流程

1. 考试页点右上角”新建考试”，在抽屉里填写后点”创建并进入扫描”。
2. 扫描页选“文件导入”，用“文件…”选择图片/PDF（可多选，双面模板请同时选中正反面），或用“文件夹…”选择包含答卷的目录，然后点“开始识别”。PDF 按各自文件内的页序配组。图片文件名都是“前缀_1、前缀_2”（面号不超过模板面数）时按前缀配组，否则按文件名排序每 2 张（单面模板每张）配一份；`IMG_0001…` 这类流水号不当面号。按顺序配组时中间缺一页会让之后的答卷串卷：命名混用、张数不成对时开始识别会提示，正反面顺序颠倒的卡带“正反面顺序”警告。识别中可暂停 / 继续，识别进行中不能切换输入源。
   “结束本轮”停止读入：扫描仪先处理完已接收的页面再释放设备；文件导入时不再读剩余文件，已读入的答卷照常识别完。之后再点“开始识别”（包括识别中途出错后），本批次已导入过的答卷（图片按文件内容、PDF 按文档和页码判断）会跳过并提示，不会重复登记。
   当前批次已结束时再点“开始识别”，会询问追加到本批次（旧结算失效，需要重新结束批次）还是新建批次。
3. 出现物理异常（红圆）时，在左栏点”重扫”选择该卡重新扫描的图片或 PDF（PDF 页数须与模板面数一致），或点”作废”。识别进行中（含暂停）不能重扫、作废或手动定位，请先点”结束本轮”。作废的卡收在左栏”已作废”折叠行里，点开后可以”恢复”为物理异常或直接重扫。
   定位失败、倾斜过大、正反面无法匹配、识别中断的卡，raw/ 里有完整原图时会多出两个按钮：“重新识别”用已保存的原图按自动定位再识别一次（程序中途退出、内部错误后常用），失败保留原记录；“手动定位”在原图上依次单击模板的参照点（定位块中心或外框四角，被遮住的可跳过，每面至少 3 个），程序按这些点纠正后重新识别，不用重扫。点定位块时会自动吸附到黑块中心；点了 4 个以上时会互相核对，某个点偏差过大或纠正后与模板对不上（点错位置或顺序）会提示失败并保留原记录。手动定位的卡带“手动定位”警告（只点 3 个时无法自检，警告里会提示重点核对），请在结果页核对。
   混卡（卡面与模板不符，`WRONG_CARD`）是定位成功后卡面标识区与模板底图对不上，说明混入了其他科目或版本的答题卡；手动定位和重新识别都无法修正，没有这两个按钮，请取出该卡后重扫正确的卡或作废。核对原图后确认确实是本科目的卡（例如学生在标识区里大面积写画）时，点“确认无误”：跳过标识检查按本模板重新识别，结果带“操作员确认”警告，请在结果页核对。
4. 全部处理完后点“结束批次”：扫描仪先排空已接收的页面；文件导入暂停时还有没读入的文件，会先确认（结束后它们不会识别）。随后重新核对异常，按整批阈值重新判定。仍有异常、空批次或重判失败时，不标成已完成；修复后可以重试。点“新批次”或切换考试时，若当前批次还有未处理的物理异常会先确认，批次保持未结束，可从考试页继续。
5. 点拼图格子或在考试页点“查看结果”进入结果页核对。
6. 在结果页切到”交付”模式点”检查交付”，按清单中的”处理方法”处理阻断项（文字转写类可直接点清单里的”补做和重试转写”或”放弃未完成转写…”，有序号的项可点”到核对里看”），然后点”生成交付目录…”，选择目标上级文件夹（默认从“文稿 / 文档”文件夹开始；不能选输出根目录、考试目录或批次目录里面，否则考试页会把交付目录当成批次列出）。生成器再次检查，并发布新的固定目录，不覆盖已有目录。

## 结算与交付

- “识别结算完成”与“可交付”分开。结算成功后，新增答卷、成功重扫、作废或恢复改变有效答卷集合，会使旧结算失效；过期结算不能把新数据误标完成。
- 已完成的工作批次可以点“重新结算”。旧格式的逐题证据元数据会升级，缺少的题图可按现有原图补建；既有图像不被反复覆盖，OCR 任务身份和已完成文字会保留。
- “检查交付”是只读检查，检查模板快照、学生/题目身份、区域顺序、每题及字段图片、整页/原图、PDF 来源及页码、路径边界和文件解码。
- OCR 明确为“未启用”可以交付；仍在等待转写会阻止交付；转写失败可以带失败清单交付。识别警告和作废答卷也会在交付记录中列出。同一批次里多份有效答卷识别出同一个完整考号时，列为说明项“多份答卷识别出同一考号”，结果页对应行标红“考号重复”并归入“有警告”：重复扫描的在扫描页作废多余的一份，不同考生的核对原图。完整性检查不等同于识别准确率或人工核对已经通过。
- 没有可用的转写配置、又不想再等时，可在结果页”交付”模式右栏点”放弃未完成转写…”：确认后把本批“等待转写”的项标为“未启用”并写回 result.json（`ocr_skipped` 记录时间和原因），交付不再被阻断，交付记录逐项列出“文字转写已放弃”。正在转写的项不改动。以后仍可用“补做和重试转写”补做。命令行对应 `scan-answer ocr-skip --batch <批次目录>`。
- 检查结果分”阻断项”和”说明项”两组，每项显示具体内容（序号、题目或文件），阻断项按类别成组并附处理去处（如”到扫描页点’结束批次’完成结算”），有现成动作的（文字转写）直接给处理按钮；有序号的项可点”到核对里看”；每组超过 3 项时先收起，点”展开其余 N 项”查看全部。检查之后数据发生变化（转写重试、放弃转写、刷新读到新数据）时，结论改为“已过期，请重新检查”。生成交付目录期间切换到别的批次，完成后仍会在页内提示行和状态栏说明哪个批次生成到了哪里。
- 结果页只在打开批次、点“刷新”、切换到结果页时重新读取数据；刷新保持当前筛选、搜索和选中的学生。当前学生因数据变化不再符合筛选（例如在“有警告”下重试成功）时，改为选中相邻的一份，并在提示行说明。
- 单项“重试转写”/“转写”和“补做和重试转写”开始后，转写按钮变灰，提示行显示进度；结束时显示完成、失败、已取消（扫描页对同一批次“继续扫描”会取消它）的项数。某一份 result.json 损坏时只跳过这一份，结束时汇总“N 份无法处理”，不影响其他答卷。信息栏（姓名等）的转写状态、失败原因也列在主观题后面，可单项重试。
- manifest 中结果路径无效的答卷归入“异常”筛选，显示“结果不可用”：可在考试页对该批次点“继续扫描”对账（能恢复的会补建结果，否则转为待重扫的异常卡），或从备份恢复。
- PgUp / PgDn 切换上一份 / 下一份，焦点在列表、卡面或答案表上都一样；只有焦点在可滚动的 JSON 文本里时用于文本翻页。
- “有警告”筛选包含仅 OCR 失败或等待转写的答卷。“证据 / JSON”按需读取选中的图片，可核对所有客观题、主观题区域、信息栏、多条码及来源；换对象、缺图或非法路径会清空旧图。
- 交付生成期间会对照源文件摘要，发现变化或写入失败时不发布半成品。成功目录含固定 JSON、图片、来源文件、模板及 `delivery.json` 检查/摘要清单，不含运行缓存与历史尝试。
- 固定交付目录可搬移、核对和读取，不可继续扫描或转写；修改在原工作批次进行，再生成一个新目录。检查已生成目录时会核对封存摘要，提示后续意外改动。
- 本包不会自动删除、覆盖坏证据。缺图可以尝试重新结算补建；坏原图、损坏模板等问题需要恢复文件、重新采集或重建批次。阻断问题未解决时不能生成交付目录。

## 模板编辑器

在模板页双击一个模板（或选中后点“编辑”）进入编辑器；点“新建模板…”从空白卡新建。编辑器左侧是区域树（按类别分组，带数量），中间是画布，右侧上方是“自动处理”（识别版面、自动定位、自动吸附）、下方是属性面板；区域树和画布之间是竖排的画框工具列，画布底部悬浮着视图条（正面 / 背面、缩放、旋转底图）；顶栏是返回、改名、撤销 / 重做、试识别和保存，底部状态行显示光标坐标（mm）、本面定位状态、纸张尺寸和操作结果。

### 制作流程

1. **新建**：填写模板名，选择空白答题卡的正面文件（扫描图片或 PDF），背面可选；不选背面时，正面多页 PDF 的第 2 页作背面（超过 2 页只用前 2 页）；另选了背面文件时正面文件只用第 1 页，多余页会在预览里提示。预览显示纸张尺寸、纠偏角度和定位方式，定位方式与新建后实际检测的结果一致。底图统一换算成 300 DPI 并纠偏。支持 A3 及以下，包括 390 × 270 mm 的 8K；正背面尺寸和方向应一致，允许 1 mm 元数据取整误差，超出时拒绝创建。
2. **确认定位**：新建时已自动检测定位块（或外框）和同步头，在画布上核对；不对时在右侧“自动定位”里重新检测，或在左侧的“画框”工具列手动画定位块 / 外框。重新检测没找到时不改动已有的定位块、外框或同步头。底图没摆正时可用画布底部的“旋转底图”手动旋转当前面（每次 0.1° 或 1°，相对正向或 180° 最多偏转 ±10°，也可整体旋转 180°；可撤销，“恢复为打开时的角度”回到原状）。画布尺寸与纸张一致、不扩展，旋转时四角少量内容会被裁掉；纠正倾斜时内容是转回纸面，裁掉的只是扫描边缘。旋转后重新“自动找定位点 / 检测外框”，并检查已画区域的位置。
3. **核对自动识别的区域**：新建时程序已从空白卡上自动识别考号、客观题块和主观题作答区（状态行写明识别到什么、哪些需要重点核对），右侧“自动处理”里的“识别版面”可随时重新识别（替换现有的考号、客观题和主观题区域，已有区域时先确认，可撤销）。识别方式：找出选项格里印的字母 / 数字，把横竖对齐的连成网格；同一位置上各题的字相同、同一题里各选项的字不同，据此分出题目方向和选项方向，并去掉混在网格里的题号；题号按版面顺序从 1 起数（同一列上的题多就先竖着数，否则先横着数），正面数完再数背面；主观题作答区是长线围起来的大块空白，跳过灰色底纹和里面有选项格的区域。需要人工核对和补充的：
   - 题型一律先设为单选，多选题、判断题要手动改；
   - 题号是按位置数的，卡上题号跳号时要改起始题号；
   - 选项数和同一面其他题块不同、只有 2 个选项、另有没用上的 0–9 填涂区（如考场号）时，状态行会点名提示；
   - 下划线式的填空题、开口的作答框、一个框里有几道题的情况认不出来或只认成一题；报考单位、姓名栏、条形码、缺考标记、选做组不自动识别。
   在模拟扫描的空白卡（倾斜、透视、模糊、噪声、JPEG 压缩）上，约九成多能把考号和全部客观题一次识别对，其余多是个别题块漏掉或选项数差一个，核对时注意状态行的提示。
4. **画区域**：在左侧的“画框”工具列点类型（考号、填涂字段、条码、缺考标记、信息栏、客观题、主观题、选做组、忽略区、标识区；定位块和外框也可以手动画），在画布上拖出框。画完自动回到“选择”。选中一道主观题再画主观题框，是给这道题追加区域（按列表顺序拼接，属性面板可删除区域）；此时状态行会醒目提示“将追加到第 N 题”。考号区和缺考标记只能各有一个，再画会替换原有的，状态行提示“已替换”，可撤销。

   **忽略区**框住会干扰自动处理、但不需要识别的内容，例如大块灰底的“阴影部分请勿作答”、贴条码的位置、常被学生涂写的空白处。框了之后：“自动定位”里的“自动找定位点 / 自动检测外框 / 自动识别同步头”把这里当白纸，不会把阴影块认成外框；识别时整页与模板比对、特征匹配兜底定位都不看这里，学生在这里大面积涂写不会导致“定位失败”。忽略区不影响填涂识别、切图和混卡检测。
   **标识区**用于检出混卡：框住印有科目 / 卷别名称、不会被书写的印刷文字（如副标题“英语（一）”“思想政治理论试题答题卡”，或各科目不同的题头），可以画多个，正面背面都可以。识别时把对齐后的卡面与底图在每个标识区内做局部相关比较（100 DPI、轻度模糊，在 ±1.5 mm 内搜索平移），可比较的标识区全部低于 0.75 才判为物理异常“混卡”（`WRONG_CARD`）；只有部分低于时多半是书写遮挡，照常识别并加“部分标识区与模板不符”警告。所以建议每个模板至少框两处标识区，单独一处被写画时会误判混卡（可在扫描页“确认无误”放行）；只由另一面推算定位的面不检查。各科目答题卡相同的部分（外框、考号区、注意事项等）不要框，否则区分不开；同一套卡只差一两个字时（如英语一 / 英语二），把标识区收紧到不同的字上（如“（一）”），并再框一处题头。底图在标识区内没有印刷内容时不参与比较，保存时会提醒。试识别同样做此检查，混卡显示为识别失败（`WRONG_CARD`）。
5. **填参数**：在属性面板填题号、题数、选项、每组题数、类型、方向等；网格按框重新生成。单选、多选之间切换只改类型，不动选项数、自定义标签和已吸附的网格；切到判断题时选项固定为 T、F（选项数固定 2），切回单选 / 多选时换成同样个数的 A、B。数值框里输入后未按回车，保存、试识别或离开页面前也会先提交。只改 X、Y、宽、高中的一项时，其余三项保持原值。
6. **吸附**：点“自动吸附”把网格对齐到印刷的选项框（选中了网格时逐个吸附选中的；什么都没选中时吸附当前面的全部网格；选中的区域里没有网格时只提示，不吸附整面），结果显示在状态行和属性面板，属性面板的位置同步为吸附后的外包框。画的框比印刷区域松一点没关系，吸附失败时会换几个初始位置重试。格子太密的网格（例如 199 的考号区）无法可靠吸附，会提示原因，这时用手柄和方向键手动对齐整块。
7. **试识别**：点“试识别…”选择已填涂样卡图片或 PDF，采用与正式识别相同的配组规则。PDF 列表显示文件名和页码。右侧列出处理状态；选中处理完成的卡，画布换成对齐图并叠加识别结果，右侧“图片 / JSON”可逐题查看客观题、主观题区域及学生字段。预览复用正式批次的题图和 JSON 组装逻辑，但只保存在内存中，未创建正式批次，也未写入输出目录。“处理完成”仍需要人工核对。编辑、撤销或重做后，旧试识别结果立即失效，迟到的后台结果也会被丢弃。“退出试识别”恢复底图，不改动模板。
8. **保存**：点“保存模板”。有问题（例如定位块不足 3 个、还没有任何识别区域、重复题号、选做引用无效）时列出问题，不保存；问题里的编号与画布、区域树一致（从 1 开始），同一网格的越界格合并成一条。定位块 3 个时按仿射变换定位，4 个更稳，状态行会注明。版本号随成功保存单调增加，撤销不会让下一次保存复用旧版本；没有修改时保存只提示“没有需要保存的修改”，不写文件也不升版本。撤销 / 重做回到上次保存的状态时，标题不再显示未保存标记。没有任何标识区时不阻止保存，但状态行提醒“未设置标识区，无法检出混卡”。底图先写入独立内容资源，再原子发布模板 JSON，保存失败保留上一版可用文件。

### 画布操作

- 点选区域，Shift 加选，空白处拖动框选；选中区域有 8 个手柄可缩放，拖动区域内部可移动。
- 方向键微调 0.1 mm（Shift 1 mm）；Delete 删除选中区域；Esc 退出画框工具。
- 滚轮缩放，按住空格拖动画布；画布底部视图条的 −、+ 缩放，点百分比回到适应窗口。
- 撤销 / 重做：顶栏按钮或 Ctrl+Z / Ctrl+Shift+Z（macOS 为 ⌘；Windows 上 Ctrl+Y 也可重做）；Ctrl+S 保存。一次拖动是一步撤销；方向键连续微调（含按住不放，间隔不超过 1 秒、选中的区域不变）合并成一步。
- 正面 / 背面切换当前编辑的面（单面模板背面按钮置灰）。
- 左侧“主观题目标”可选新建题，或追加至任意已有题；切换正背面保留目标。选中一道主观题时自动将其设为追加目标，点画布空白处取消选中后恢复为“新建主观题”；在下拉框里手动选的目标会一直保留，要另建题，先选“新建主观题”。
- 标题旁“改名…”修改模板名（可撤销，保存后写入模板；不改已有目录名）。
- 主观题属性中的区域列表可上移、下移、删除，顺序就是正式结果的区域图片顺序；调整题号或小题号会同步选做组引用。仍被选做组引用的题不能直接删除。
- 左侧“当前面定位方式”可手动切换定位块或外框；另一种方式已有的矩形会保留，切回后可继续使用。手动画定位块或外框会启用对应方式。

### 保存位置

- 打开已有模板时保存回原目录。
- 随程序提供的模板（程序目录 `templates/` 下）和不可写的目录不会被改动，另存到用户模板目录并提示；之后的修改都保存在新目录。另存时如果没改过名，名称自动加“（副本）”，避免列表里出现两个同名模板。
- 模板列表的“添加模板目录…”添加的目录里没有模板时会提示（目录仍会记住）；“移除目录…”把添加过的目录从列表中移除，只改设置，不删除文件。随程序提供的模板目录和用户模板目录总会显示，不能移除。
- 新建的模板保存到用户模板目录：macOS `~/Library/Application Support/scan-answer/templates/<模板名>/`，Windows `%APPDATA%\scan-answer\templates\<模板名>\`；重名时加 `_2`、`_3`。用户模板目录总会出现在模板列表和考试页的模板下拉框里。
- 离开模板页或关闭窗口时，如果模板有未保存的修改，会询问“保存 / 放弃修改 / 取消”（默认保存）；保存不成功（例如校验不过）时留在编辑器。
- 底图资源优先用硬链接排他发布；所在磁盘不支持硬链接（exFAT、FAT、部分网络盘）时改为排他新建文件写入，失败时清理临时文件。

### 考试的模板版本

新建考试会把所选模板和底图复制到考试目录的 `template/`，此后新建批次均使用这个固定快照。修改源模板不会改变已有考试；需要使用新版模板时新建考试并明确选择。页面显示模板名称和版本，刷新模板列表会保留仍存在的选择。

旧考试在下次新建批次前固定模板：有历史批次时采用一致的历史模板快照；若历史批次模板内容冲突则拒绝继续猜测版本，应另建考试。没有历史批次时固定当前所引用的源模板。仅查看考试列表不会迁移或改写考试。

考试页：
- 考试列表点一行原位展开：显示科目代码、考场、操作员、创建日期、模板快照和批次子表；点行左侧三角或按 ← / → 收起、展开。双击考试直接扫描新批次，双击批次打开结果页。
- 新建考试在右侧抽屉里（点遮罩、按 Esc、点关闭或取消收起，填写的内容保留）；新建考试的输入框按回车只跳到下一项，点”创建并进入扫描”才创建；创建后表单清空（模板保留）。已有同名（名称、科目相同）考试时先确认。操作员默认取设置里的“默认操作员”，没有手动改过时随设置更新。
- 扫描进行中（含暂停）不能新建考试、切换考试或继续另一个批次：提示后跳到扫描页，等本轮完成或点“结束本轮”后再操作。
- 模板快照缺失或损坏的考试不能进入扫描（提示新建考试并选择模板），当前批次不受影响。
- 刷新（回到考试页、结算完成、保存设置）时保留选中的考试和批次。批次列表的状态列标出扫描页当前打开的批次（“已打开”/“扫描中”）；已结算的批次点“继续扫描”时，扫描页会让你选择追加到该批次或新建批次。考试目录里的固定交付目录不算批次。
- 输出根目录不存在或无法读取时，考试列表直接提示该路径，而不是显示“还没有考试”。
- 顶栏显示当前页面对应的考试：结果页显示所查看批次的考试，其他页面显示扫描页的考试。

## 数据位置

- 设置：macOS `~/Library/Application Support/scan-answer/settings.json`；Windows `%APPDATA%\scan-answer\settings.json`
  - 注意：大模型转写的 API Key 以**明文**保存在 settings.json 里，请勿把该文件拷给他人或提交到代码仓库。关闭转写后连接配置仍保留在 `ocr_saved` 字段，重新启用不用再填。
  - settings.json、exam.json、manifest.json、template.json 损坏或结构不对时程序照常启动：设置回退默认值，列表里跳过坏的考试 / 批次 / 模板。
- 输出：设置中的“输出根目录”下，`<考试>/<批次>/`，格式见 `docs/output-format.md`

## 说明

- 文件输入在 macOS 和 Windows 上都可用；扫描仪输入仅在 Windows 和相应 TWAIN 驱动可用时启用。
- 程序意外退出后，在考试页展开那场考试，在该批次行尾点”继续扫描”即可恢复（自动对账，中断的卡标为物理异常，可重扫）。

## 手写转写的生命周期

- 识别成功的卡在后台排队转写，扫描不等待转写。
- 结束批次后新建批次、切换考试、继续另一个批次时，上一批次**未完成的转写在后台继续转完**：结果写回该批次的 result.json，进度写进该批次的 manifest（考试页可看到），扫描页与状态栏的转写计数只反映当前批次。
- 在考试页对同一个批次点“继续扫描”时，会先取消它残留的后台转写，再对账，并把仍为“等待转写”的项重新投递。
- 首次转写、结果页单项重试、“补做和重试转写”共用任务身份。重复操作不会重复发送同一有效请求；旧请求在取消、结果替换或任务代次更新后，成功和失败都不能覆盖新结果。切换学生或批次后，旧重试回调只更新自己的批次。
- 新建或重新打开批次时，当前 OCR 配置决定后续新扫描的转写开关；历史已完成项不被重置，历史未启用项通过“补做和重试转写”补做。重新打开时没有 OCR 配置，旧等待项仍可恢复，但不会为新答卷制造无人处理的新任务。
- 关闭窗口时如果还有转写未完成（包括当前、后台批次和结果页重试），会提示剩余项数；确定退出则取消全部转写，剩余项保留为“等待转写”，下次配置 OCR 后“继续扫描”该批次（或命令行 `scan-answer ocr`）时接着转写。退出时不等待正在进行的网络请求，迟到请求也不能继续回写。

## 扫描仪（Windows）

- 扫描页“输入源”选“扫描仪”（需要 Windows、64 位 TWAIN 驱动和 TWAINDSM.dll；不满足时按钮置灰，悬停可以看到原因）。从下拉框选扫描仪，没有列出时检查电源和 USB 后点“刷新”。
- 模板面数必须与单双面设置一致。进纸器、自动进纸、单双面、分辨率单位及横纵 DPI 必须设置成功并回读一致，否则不开始采集；可选的色彩、滤色、裁边等设置不支持时会提示。本次使用的参数会记住，下次默认沿用。
- 点“开始识别”后扫描仪连续进纸。进纸器空、双张或卡纸时自动暂停，中栏上方的通知条说明原因：
  - 双张、卡纸：已接收页面保留。出现缺面异常时，先结束本轮，按异常原序号整份重扫，再继续其余答卷；不把半份与下一轮首面自动拼接；
  - 进纸器空：放入下一叠后点“继续”；全部扫完点“结束批次”。
- 页面在扫描回调中先保存到批次 `acquisition/`，队列传文件信息。暂停不会阻塞已提交识别任务的结果登记。
- “结束本轮”进入“停止收尾中”：排空已接收页面及半份，再等待设备释放，批次保持打开。确认释放前不能新扫、重扫或切换批次；超时明确提示仍被占用。
- 物理异常用扫描仪重扫前，需要先结束本轮：点“重扫”，按提示把完整答卷放进进纸器，结果沿用原序号。重扫过程有独立占用状态，不能重复启动。
- 重扫新图先在 `attempts/` 保存和识别；缺面、坏图、写入或识别失败时旧证据保持可用。成功后才提交替换并保留旧记录的历史副本；提交中断时重开批次恢复。失败的重扫不会把原来已作废的卡重新变成未处置异常。
- 导入图片模式下，重扫时选择重扫后的图片文件。
- 意外退出后，未登记的采集页按原轮次、原配对位置恢复为有原图的待重扫异常；已经登记或归入重扫历史的页面不会再计为新学生。损坏的重扫历史日志单独保留并记录恢复警告，不能据此猜测结果已经安全发布。

## 填写答卷 PDF 与逐题图片

- 扫描页和试识别都接受填写好的 PDF，不需要先手工转成图片；新建模板的空白 PDF 导入是另一项功能。
- 单面模板每页一份，双面模板每两页一份。每个 PDF 独立配组，奇数尾页记为缺面，不会拿下一份 PDF 的首页补齐。
- 坏文件、密码保护或渲染失败会显示文件名/页码错误，停止本次输入；已经写出的结果保留，批次不会自动标记为已完成。
- PDF 按默认 300 DPI 渲染。页面尺寸不写死，模板采用实际毫米坐标，支持 A3 及以下的 A3、8K、A4/A5 和自定义纸幅；不同版式仍需各自的正确模板。
- 原 PDF 保存在批次的 `sources/`，渲染页保存在 `raw/`，JSON 记录来源文件、页码和相对路径。
- 正常客观题也有独立题图；主观题按模板的区域顺序输出多图。具体路径与题目身份见 `docs/output-format.md`，不要依赖旧文件名拼接。

## 颜色滤除与裁边

- 扫描页和设置页的“颜色滤除”可以选无、红、绿、蓝：去掉卡面上该颜色的印刷（底纹、浅色选项框），让涂黑更突出。
  - 灰度扫描时由扫描仪滤色；扫描仪不支持时，通知条里会提示。
  - 彩色扫描时由软件取对应的颜色通道，原图保存的是滤色后的灰度图。
- “裁边”：
  - 自动：扫描仪检测纸边，裁掉背板；
  - 按模板：按当前模板的纸张尺寸裁切；
  - 驱动：不设置，用驱动自己的默认值。

  识别不依赖裁边，这一项只影响原图的大小。

## 输出目录命名

设置页“输出”一节：
- **考试目录命名**：默认是 `{name}_{subject}_{time}`。可用的占位符有 `{name}` `{subject}` `{code}` `{site}` `{room}` `{operator}` `{date}` `{time}`。重名时自动加 `_2`、`_3`。
- **学生目录命名**：只控制序号之后的部分，默认是 `{exam_no}`。可用的占位符有 `{exam_no}`（考号没有完整识别时为空）、`{barcode}`。留空则只用序号。

规则写错时会提示，不能保存；“示例”一行实时显示效果。学生目录的规则在新建批次时记入批次，之后修改设置不影响已有批次。

设置保存先完成全部校验和写盘，再更新有效内存配置；失败不改变当前配置。每次进入设置页都按当前设置重新填表（扫描页会记住上次使用的扫描参数）；保存只写回表单里实际改动的项，不会用旧值覆盖扫描页记住的参数。离开设置页时有未保存的修改会询问保存、放弃或取消。输出根目录不能为空。保存后的默认扫描参数在就绪时立即进入扫描页，若本轮正在运行则延后到收尾后应用；进程池和 OCR 配置仍在新建或重新打开批次时确定。设置页顶部常驻"保存设置"，有改动时列出未保存的项；左侧目录在改过的节旁标圆点，改过的字段显示原来的值。大模型转写的 base_url、api_key 显示为"接口地址""密钥"。

## 命令行交付

```sh
scan-answer check --batch /path/to/working-batch
scan-answer deliver --batch /path/to/working-batch --out /path/to/new-delivery
```

`check` 输出 JSON 检查结果，不改动批次；通过返回 0，存在阻断项返回 1。`deliver` 必须使用新目标目录，通过后输出目录路径。`recognize` 遇到未处置物理异常或重判失败也返回非零，但保留已经生成的工作目录。
