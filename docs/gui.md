# 图形界面使用说明（第 1 期）

启动：`scan-answer-gui`（开发环境：`.venv/bin/scan-answer-gui`）。

使用 uv 时，在项目根目录运行 `uv run scan-answer-gui`，或
`uv run python -m scan_answer.ui.app`。也支持直接运行或 Debug
`src/scan_answer/ui/app.py`。IDE 解释器应选择项目的 `.venv/bin/python`
（Windows 为 `.venv\Scripts\python.exe`），工作目录设为项目根目录；
首次准备环境先运行 `uv sync --extra dev`。

命令行入口是 `src/scan_answer/cli.py`，支持
`uv run python src/scan_answer/cli.py --help`、`uv run python -m scan_answer.cli --help`
和 `uv run scan-answer --help`。直接 Debug 此文件时，在运行配置中填写
`--help` 或实际子命令参数；CLI 不带参数会提示缺少必需的子命令，不会打开图形界面。

## 页面

| 页面 | 做什么 |
|---|---|
| 考试 | 新建考试（名称、科目、考点、操作员、模板）；查看各考试的批次，继续扫描、查看结果、打开目录 |
| 扫描 | 选择扫描仪、图片/PDF 文件或文件夹并开始识别；批次拼图实时显示每张卡的状态；处理物理异常（重扫 / 作废）；结束批次 |
| 模板 | 列出可用模板、添加模板目录；新建模板、在可视化编辑器里修改模板（见下文“模板编辑器”） |
| 结果 | 按全部 / 有警告 / 异常筛选学生；卡面叠层、每题及任意字段图片、来源和 JSON；检查交付、生成固定交付目录 |
| 设置 | 扫描默认参数、识别进程数、大模型转写（含测试连接）、输出根目录、默认操作员 |

## 典型流程

1. 考试页填写“新建考试”，点“创建并进入扫描”。
2. 扫描页选“文件导入”，用“文件…”选择图片/PDF，或用“文件夹…”选择包含答卷的目录，然后点“开始识别”。图片按既有文件名规则配组；PDF 按各自文件内的页序配组。识别中可暂停 / 继续。
3. 出现物理异常（红圆）时，在左栏点“重扫”选择该卡重新扫描的图片，或点“作废”。
4. 全部处理完后点“结束批次”：后台排空采集后重新核对异常，按整批阈值重新判定。仍有异常、空批次或重判失败时，不标成已完成；修复后可以重试。
5. 点拼图格子或在考试页点“查看结果”进入结果页核对。
6. 在结果页点“检查交付”，处理阻断项后点“生成交付目录…”，选择目标上级文件夹。生成器再次检查，并发布新的固定目录，不覆盖已有目录。

## 结算与交付

- “识别结算完成”与“可交付”分开。结算成功后，新增答卷、成功重扫、作废或恢复改变有效答卷集合，会使旧结算失效；过期结算不能把新数据误标完成。
- 已完成的工作批次可以点“重新结算”。旧格式的逐题证据元数据会升级，缺少的题图可按现有原图补建；既有图像不被反复覆盖，OCR 任务身份和已完成文字会保留。
- “检查交付”是只读检查，检查模板快照、学生/题目身份、区域顺序、每题及字段图片、整页/原图、PDF 来源及页码、路径边界和文件解码。
- OCR 明确为“未启用”可以交付；仍在等待转写会阻止交付；转写失败可以带失败清单交付。识别警告和作废答卷也会在交付记录中列出。完整性检查不等同于识别准确率或人工核对已经通过。
- “有警告”筛选包含仅 OCR 失败的答卷。“证据 / JSON”按需读取选中的图片，可核对所有客观题、主观题区域、信息栏、多条码及来源；换对象、缺图或非法路径会清空旧图。
- 交付生成期间会对照源文件摘要，发现变化或写入失败时不发布半成品。成功目录含固定 JSON、图片、来源文件、模板及 `delivery.json` 检查/摘要清单，不含运行缓存与历史尝试。
- 固定交付目录可搬移、核对和读取，不可继续扫描或转写；修改在原工作批次进行，再生成一个新目录。检查已生成目录时会核对封存摘要，提示后续意外改动。
- 本包不会自动删除、覆盖坏证据。缺图可以尝试重新结算补建；坏原图、损坏模板等问题需要恢复文件、重新采集或重建批次。阻断问题未解决时不能生成交付目录。

## 模板编辑器

在模板页双击一个模板（或选中后点“编辑”）进入编辑器；点“新建模板…”从空白卡新建。编辑器左侧是区域树（按类别分组，带数量），中间是画布，右侧是属性面板；顶部是工具栏，底部状态行显示光标坐标（mm）、本面定位状态、纸张尺寸和操作结果。

### 制作流程

1. **新建**：填写模板名，选择空白答题卡的正面文件（扫描图片或 PDF），背面可选；正面选 2 页的 PDF 时自动用第 2 页作背面（超过 2 页只用前 2 页）。预览显示纸张尺寸、纠偏角度和检测到的定位方式。底图统一换算成 300 DPI 并纠偏。支持 A3 及以下，包括 390 × 270 mm 的 8K；正背面尺寸和方向应一致，允许 1 mm 元数据取整误差，超出时拒绝创建。
2. **确认定位**：新建时已自动检测定位块（或外框）和同步头，在画布上核对；不对时用工具栏重新检测，或用区域工具手动画定位块 / 外框。
3. **画区域**：区域工具下拉框选类型（考号、填涂字段、条码、缺考标记、信息栏、客观题、主观题、选做组、忽略区；定位块和外框也可以手动画），在画布上拖出框。画完自动回到“选择”。选中一道主观题再画主观题框，是给这道题追加区域（按列表顺序拼接，属性面板可删除区域）。
4. **填参数**：在属性面板填题号、题数、选项、每组题数、类型、方向等；网格按框重新生成。
5. **吸附**：点“自动吸附”把网格对齐到印刷的选项框（选中了网格时逐个吸附选中的，没选中时吸附当前面的全部网格），结果显示在状态行和属性面板。画的框比印刷区域松一点没关系，吸附失败时会换几个初始位置重试。格子太密的网格（例如 199 的考号区）无法可靠吸附，会提示原因，这时用手柄和方向键手动对齐整块。
6. **试识别**：点“试识别…”选择已填涂样卡图片或 PDF，采用与正式识别相同的配组规则。PDF 列表显示文件名和页码。右侧列出处理状态；选中处理完成的卡，画布换成对齐图并叠加识别结果，右侧“图片 / JSON”可逐题查看客观题、主观题区域及学生字段。预览复用正式批次的题图和 JSON 组装逻辑，但只保存在内存中，未创建正式批次，也未写入输出目录。“处理完成”仍需要人工核对。编辑、撤销或重做后，旧试识别结果立即失效，迟到的后台结果也会被丢弃。“退出试识别”恢复底图，不改动模板。
7. **保存**：点“保存模板”。有问题（例如定位块不足 4 个、重复题号、选做引用无效）时列出问题，不保存。版本号随成功保存单调增加，撤销不会让下一次保存复用旧版本。底图先写入独立内容资源，再原子发布模板 JSON，保存失败保留上一版可用文件。

### 画布操作

- 点选区域，Shift 加选，空白处拖动框选；选中区域有 8 个手柄可缩放，拖动区域内部可移动。
- 方向键微调 0.1 mm（Shift 1 mm）；Delete 删除选中区域；Esc 退出画框工具。
- 滚轮缩放，按住空格拖动画布；工具栏 −、+ 缩放，点百分比回到适应窗口。
- 撤销 / 重做：工具栏按钮或 Ctrl+Z / Ctrl+Shift+Z（macOS 为 ⌘）；Ctrl+S 保存。
- 正面 / 背面切换当前编辑的面（单面模板背面按钮置灰）。
- 左侧“主观题目标”可选新建题，或追加至任意已有题；切换正背面保留目标。选中一道主观题时自动将其设为追加目标；要另建题，先选“新建主观题”。
- 主观题属性中的区域列表可上移、下移、删除，顺序就是正式结果的区域图片顺序；调整题号或小题号会同步选做组引用。仍被选做组引用的题不能直接删除。
- 左侧“当前面定位方式”可手动切换定位块或外框；另一种方式已有的矩形会保留，切回后可继续使用。手动画定位块或外框会启用对应方式。

### 保存位置

- 打开已有模板时保存回原目录。
- 随程序提供的模板（程序目录 `templates/` 下）和不可写的目录不会被改动，另存到用户模板目录并提示；之后的修改都保存在新目录。
- 新建的模板保存到用户模板目录：macOS `~/Library/Application Support/scan-answer/templates/<模板名>/`，Windows `%APPDATA%\scan-answer\templates\<模板名>\`；重名时加 `_2`、`_3`。用户模板目录总会出现在模板列表和考试页的模板下拉框里。
- 离开模板页或关闭窗口时，如果模板有未保存的修改，会询问是否放弃。

### 考试的模板版本

新建考试会把所选模板和底图复制到考试目录的 `template/`，此后新建批次均使用这个固定快照。修改源模板不会改变已有考试；需要使用新版模板时新建考试并明确选择。页面显示模板名称和版本，刷新模板列表会保留仍存在的选择。

旧考试在下次新建批次前固定模板：有历史批次时采用一致的历史模板快照；若历史批次模板内容冲突则拒绝继续猜测版本，应另建考试。没有历史批次时固定当前所引用的源模板。仅查看考试列表不会迁移或改写考试。

## 数据位置

- 设置：macOS `~/Library/Application Support/scan-answer/settings.json`；Windows `%APPDATA%\scan-answer\settings.json`
  - 注意：大模型转写的 API Key 以**明文**保存在 settings.json 里，请勿把该文件拷给他人或提交到代码仓库。
  - settings.json、exam.json、manifest.json、template.json 损坏或结构不对时程序照常启动：设置回退默认值，列表里跳过坏的考试 / 批次 / 模板。
- 输出：设置中的“输出根目录”下，`<考试>/<批次>/`，格式见 `docs/output-format.md`

## 说明

- 文件输入在 macOS 和 Windows 上都可用；扫描仪输入仅在 Windows 和相应 TWAIN 驱动可用时启用。
- 程序意外退出后，在考试页选中批次点“继续扫描”即可恢复（自动对账，中断的卡标为物理异常，可重扫）。

## 手写转写的生命周期

- 识别成功的卡在后台排队转写，扫描不等待转写。
- 结束批次后新建批次、切换考试、继续另一个批次时，上一批次**未完成的转写在后台继续转完**：结果写回该批次的 result.json，进度写进该批次的 manifest（考试页可看到），扫描页与状态栏的转写计数只反映当前批次。
- 在考试页对同一个批次点“继续扫描”时，会先取消它残留的后台转写，再对账，并把仍为“等待转写”的项重新投递。
- 首次转写、结果页单项重试、“补做和重试转写”共用任务身份。重复操作不会重复发送同一有效请求；旧请求在取消、结果替换或任务代次更新后，成功和失败都不能覆盖新结果。切换学生或批次后，旧重试回调只更新自己的批次。
- 新建或重新打开批次时，当前 OCR 配置决定后续新扫描的转写开关；历史已完成项不被重置，历史未启用项通过“补做和重试转写”补做。重新打开时没有 OCR 配置，旧等待项仍可恢复，但不会为新答卷制造无人处理的新任务。
- 关闭窗口时如果还有转写未完成（包括当前、后台批次和结果页重试），会提示剩余项数；确定退出则取消全部转写，剩余项保留为“等待转写”，下次配置 OCR 后“继续扫描”该批次（或命令行 `scan-answer ocr`）时接着转写。退出时不等待正在进行的网络请求，迟到请求也不能继续回写。

## 扫描仪（Windows）

- 扫描页“输入源”选“扫描仪”（需要 Windows、64 位 TWAIN 驱动和 TWAINDSM.dll；不满足时按钮置灰，悬停可以看到原因）。从下拉框选扫描仪，没有列出时检查电源和 USB 后点“刷新”。
- 模板面数必须与单双面设置一致。进纸器、自动进纸、单双面、分辨率单位及横纵 DPI 必须设置成功并回读一致，否则不开始采集；可选的色彩、滤色、裁边等设置不支持时会提示。本次使用的参数会记住，下次默认沿用。
- 点“开始识别”后扫描仪连续进纸。进纸器空、双张或卡纸时自动暂停，中栏上方的通知条说明原因：
  - 双张、卡纸：已接收页面保留。出现缺面异常时，先结束本轮，按异常原序号整份重扫，再继续其余答卷；不把半份与下一轮首面自动拼接；
  - 进纸器空：放入下一叠后点“继续”；全部扫完点“结束批次”。
- 页面在扫描回调中先保存到批次 `acquisition/`，队列传文件信息。暂停不会阻塞已提交识别任务的结果登记。
- “结束本轮”进入“停止收尾中”：排空已接收页面及半份，再等待设备释放，批次保持打开。确认释放前不能新扫、重扫或切换批次；超时明确提示仍被占用。
- 物理异常用扫描仪重扫前，需要先结束本轮：点“重扫”，按提示把完整答卷放进进纸器，结果沿用原序号。重扫过程有独立占用状态，不能重复启动。
- 重扫新图先在 `attempts/` 保存和识别；缺面、坏图、写入或识别失败时旧证据保持可用。成功后才提交替换并保留旧记录的历史副本；提交中断时重开批次恢复。失败的重扫不会把原来已作废的卡重新变成未处置异常。
- 导入图片模式下，重扫时选择重扫后的图片文件。
- 意外退出后，未登记的采集页按原轮次、原配对位置恢复为有原图的待重扫异常；已经登记或归入重扫历史的页面不会再计为新学生。损坏的重扫历史日志单独保留并记录恢复警告，不能据此猜测结果已经安全发布。

## 填写答卷 PDF 与逐题图片

- 扫描页和试识别都接受填写好的 PDF，不需要先手工转成图片；新建模板的空白 PDF 导入是另一项功能。
- 单面模板每页一份，双面模板每两页一份。每个 PDF 独立配组，奇数尾页记为缺面，不会拿下一份 PDF 的首页补齐。
- 坏文件、密码保护或渲染失败会显示文件名/页码错误，停止本次输入；已经写出的结果保留，批次不会自动标记为已完成。
- PDF 按默认 300 DPI 渲染。页面尺寸不写死，模板采用实际毫米坐标，支持 A3 及以下的 A3、8K、A4/A5 和自定义纸幅；不同版式仍需各自的正确模板。
- 原 PDF 保存在批次的 `sources/`，渲染页保存在 `raw/`，JSON 记录来源文件、页码和相对路径。
- 正常客观题也有独立题图；主观题按模板的区域顺序输出多图。具体路径与题目身份见 `docs/output-format.md`，不要依赖旧文件名拼接。

## 颜色滤除与裁边

- 扫描页和设置页的“颜色滤除”可以选无、红、绿、蓝：去掉卡面上该颜色的印刷（底纹、浅色选项框），让涂黑更突出。
  - 灰度扫描时由扫描仪滤色；扫描仪不支持时，通知条里会提示。
  - 彩色扫描时由软件取对应的颜色通道，原图保存的是滤色后的灰度图。
- “裁边”：
  - 自动：扫描仪检测纸边，裁掉背板；
  - 按模板：按当前模板的纸张尺寸裁切；
  - 驱动：不设置，用驱动自己的默认值。

  识别不依赖裁边，这一项只影响原图的大小。

## 输出目录命名

设置页“输出”一节：
- **考试目录命名**：默认是 `{name}_{subject}_{time}`。可用的占位符有 `{name}` `{subject}` `{code}` `{site}` `{room}` `{operator}` `{date}` `{time}`。重名时自动加 `_2`、`_3`。
- **学生目录命名**：只控制序号之后的部分，默认是 `{exam_no}`。可用的占位符有 `{exam_no}`（考号没有完整识别时为空）、`{barcode}`。留空则只用序号。

规则写错时会提示，不能保存；“示例”一行实时显示效果。学生目录的规则在新建批次时记入批次，之后修改设置不影响已有批次。

设置保存先完成全部校验和写盘，再更新有效内存配置；失败不改变当前配置。保存后的默认扫描参数在就绪时立即进入扫描页，若本轮正在运行则延后到收尾后应用；进程池和 OCR 配置仍在新建或重新打开批次时确定。

## 命令行交付

```sh
scan-answer check --batch /path/to/working-batch
scan-answer deliver --batch /path/to/working-batch --out /path/to/new-delivery
```

`check` 输出 JSON 检查结果，不改动批次；通过返回 0，存在阻断项返回 1。`deliver` 必须使用新目标目录，通过后输出目录路径。`recognize` 遇到未处置物理异常或重判失败也返回非零，但保留已经生成的工作目录。
