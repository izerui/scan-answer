答题卡识别模块 · 对接与场景演示考研系统 ⇄ 答题卡识别模块

整体说明

考研系统负责组卷、发布考试、批改、成绩，以及面向学校老师和学生的全部界面。答题卡识别模块是一个后台服务，没有面向学校用户的界面，只通过接口和考研系统交互，负责三件事：

  1. 答题卡样式库：已适配的考研标准答题卡样式（带定位标、版式码、考号填写区），供考研系统选择；
  2. 答题卡生成与下载：接收考研系统发来的题目结构，按选定样式生成答题卡 PDF，支持参数调整，提供下载；
  3. 整卷识别拆解回传：接收考研系统转来的扫描 PDF，校正、匹配版式、识别考号完成归属、按题切图、识别选择题、识别手写内容，按约定结构回传。

识别模块只识别、不判分；批改、校准、成绩全部在考研系统完成。

系统边界

👩‍🏫 学校老师 / 考务：录题、下载打印、上传扫描 PDF、处理异常

🖨 扫描仪：用自带软件扫成 PDF（模块不控制扫描仪）

主流程

① 录题 / 组卷→ ② 同步学生名单→ ③ 生成答题卡→ ④ 预览、调整、下载→ ⑤ 打印、考试、扫描成 PDF→ ⑥ 上传扫描 PDF→ ⑦ 识别、切图、校验→ ⑧ 回调回传→ ⑨ 查看结果、补全异常、批改

设计原则

  • 对下游透明：回传数据直接落到考研系统现有的逐题作答模型，批改、成绩流程不改。
  • 切图优先于文字识别：切图是老师批改的依据，必须准确；手写识别文字只作辅助，带置信度。
  • 归属宁疑勿错：考号不确定时绝不自动归属，作为异常回传，由考研系统人工补全。
  • 失败不丢数据：任何识别失败都要有异常记录和原始页面图，不能静默丢弃。
  • 处理完再回传：一个扫描任务全部处理完、校验完，再一次性回传。
  • 私有化部署：一套考研系统对接一套识别模块，数据不出部署环境。

异常与关键规则

  

    
异常码

    

  

  

    

      
怎么确定是哪场考试

      
    
        
  • 生成答题卡时，识别模块登记"版式码 ↔ 考试 ID"。
    • 
        
  • 卡面上同时有考试 ID（手填或预印）：和版式码登记的考试必须一致，不一致记 EXAM_ID_MISMATCH，不自动归属。
    • 
        
  • 卡面没有考试 ID：按版式码登记的考试确定。
    • 
        
  • 版式码读不出：按卡面考试 ID 确定；两者都没有，记 LAYOUT_CODE_UNREADABLE。
    • 
      

      
怎么确定是哪个学生

      
    
        
  • 手填卡：学号填涂（OMR）为主、手写誊写（OCR）为辅，两者一致且在名单内才自动归属。
    • 
        
  • 预印卡：直接读取预印信息，identifier_source = printed。
    • 
        
  • 不一致、置信度不足、不在名单内：不归属，作为异常回传，附考号区切图。
    • 
      

    

    

      
回传前校验

      
    
        
  • 每份卷子的考试 ID 是已登记考试；
    • 
        
  • 每份已归属卷子的学号在该考试名单内；
    • 
        
  • 版式与考试一致；
    • 
        
  • 选择题、切图、手写识别全部完成；
    • 
        
  • 处理不了的卷子都已标为异常，并保留原始页面图。
    • 
      

      
异常卷子的处理

      
    
        
  • 识别模块不做人工界面，异常随结果一起回传。
    • 
        
  • 每份卷子都带 batch_label（批次说明）和 batch_seq（批次内顺序号），异常卷子另带前后两份卷子的学号，方便判断班级、考场。
    • 
        
  • 能切题的（如考号读不出）：照常回传切图和选择题答案，考研系统人工选学生即可入库。
    • 
        
  • 不能切题的（如版式码损坏）：回传整页原图，由考研系统人工处理。
    • 
      

      
重复与重新拉取

      
    
        
  • 按"考试 ID + 学号 + 页码"去重；同一 PDF 重复上传不产生新结果。
    • 
        
  • 整卷重扫用 replace=true 上传，以最新一次覆盖，sheet_uid 不变、version 加一。
    • 
        
  • 考研系统可按任务、考试、单份卷子重新拉取结果；按 sheet_uid + version 入库，不会重复。
