# 工作包 2：模板制作、考试绑定和试识别闭环

用户已确认开始。基于工作包 1 的未提交源码继续修改，保留其 PDF 输入、逐题图片和来源信息。沿用当前 PySide6 界面与毫米坐标，不更换技术栈，不加入评分或业务对接。

## 目标与实现选择

从空白卡出发，不手改 JSON 即可建立跨面题目、调整区域顺序、确认定位方式、校验保存、试识别核对题图，再创建使用固定模板版本的考试。

采用现有 `TemplateDoc` 统一管理修改；内容修订号用于试识别有效性，保存版本号独立于撤销历史。考试保存完整快照，批次继续复制考试快照。没有选择让所有页面各自修改模板，也不把运行时识别数据回写为模板内容。

## 模板数据层

- `TemplateDoc.revision`：初始 0，每次有效的内容修改与 undo/redo 增加；保存元数据变化不使同内容试识别失效。
- `set_alignment_method(face, method)`：显式切换 anchors/frames，保留另一方式的矩形供切回；手动画定位块/外框时自动启用对应方式，并返回正确全局引用。
- `move_subjective_region(index, old, new) -> RegionRef`：在同一题的区域列表移动，允许跨面，输出顺序随列表。
- 现有 `add_subjective_region` 继续使用。UI 选择全模板中的目标题，切面不丢失追加目标。
- 修改主观题题号/小题号时同步更新选做引用；冲突和空键在变更前拒绝。改变客观题范围时同步已有位置对应的引用；删除仍被引用的题时明确阻止，先要求调整选做组。
- 选做组默认使用主观题完整 key；题数变化时在原外包框内重新均分格子，同数量只改引用，不移动格子。
- 新建模板拒绝正背面尺寸或方向明显不一致；物理尺寸误差不超过 1 mm 时统一到第一面的像素尺寸。支持 A3 及以下，超过长边 420 mm、短边 297 mm（允许 1 mm 元数据取整误差）给出明确错误。
- 保存版本单调递增，不随撤销回退；模板目录名处理特殊名字，不让 `.`、`..` 或 Windows 保留名成为异常路径。

## 校验与保存

`validate_template` 返回可读的问题列表，不因网格、标签不匹配而先抛索引错误。覆盖纸张/DPI、有效面、全部定位/作答矩形、所有 OMR 网格、字段空键/重复键、题号、小题、选做引用和区域非空。

`save_template(t, directory, bases=None)` 保持签名。带底图保存时，底图先写入内容摘要命名的资源文件，再原子替换 JSON；JSON 只有在所有资源就绪后才发布，失败保留旧 JSON 和它引用的旧资源。成功后同步 `t.faces.*.image`。不覆盖旧资源，因此不会在 JSON 提交前破坏旧模板。

读取和保存都拒绝越出模板目录的底图引用。没有传 bases 的旧调用仍保留原引用。模板另存使用 JSON 声明的资源，不依赖文件叫 front.png/back.png。

## 考试固定模板

- 新考试创建时在考试目录保存完整 `template/` 快照，exam.json 使用相对引用并记录模板名/版本和来源；创建失败不留下可选的半成品考试。
- `ensure_exam_snapshot(exam) -> Path`：新建批次前保证考试有固定模板。已有快照直接使用。旧考试若已有批次，优先采用其一致的历史模板快照；历史版本冲突时明确报错，要求新建考试选择版本，不能自动猜测。没有历史批次时固定当前来源模板。
- `load_exam` 保持旧格式读取兼容，不在列考试时自动迁移。
- 考试页刷新保留当前模板选择；模板保存后可选中新模板。扫描页和状态栏显示模板名及版本，不显示无意义的快照目录名。
- 已有考试不会随源模板修改而自动升级；使用新版模板通过新建考试明确选择。本包不添加隐式升级功能。

## 编辑器和试识别

- 左侧增加当前面定位方式和“主观题目标”选择：新建题或追加至全模板中某道题，选中题时自动选作目标，切换正反面保持目标。
- 属性面板为每个主观题区域提供上移、下移、删除；每项修改可撤销。
- `TrialSheet` 增加内存中的最终 result 和 images；试识别调用与正式识别相同的 `render_images/build_result`，不写正式结果文件。
- 试识别右侧提供题图/字段图片选择、状态摘要及只读 JSON；中间仍为整页叠层。预览清楚标明尚未写入批次。
- 试识别绑定 doc 对象和内容 revision；编辑、撤销、重做使旧结果失效。迟到回调不能恢复旧结果。
- 界面使用“处理完成、待核对”，而非把未抛异常等同于答案正确；查看异常与题图后由操作者核对，不引入评分。
