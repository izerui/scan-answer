# 考试 / 扫描 / 结果 / 设置四页按功能区重排 设计

## 为什么

用户反馈各页面“操作按钮散落各处，不知道怎么用”。模板编辑页已按功能区重排（`2026-11-11-template-editor-layout-design.md`），其余四页照同一原则改：同一对象的操作放在一起、全页只有一个当前最该点的主按钮、先后顺序看得出来。

## 用户选定（原话见 `design-demos/direction-approved.md`）

「考试页 用 B 。 扫描页 用C ，  结果页用B ， 设置页 用A。 注意保证功能都在，别重构后丢失功能」

|---|---|---|---|

| 扫描页 | C 左管批次、右管本轮 | `design-demos/pages/scan-C-本轮与批次分栏.html`（可点：折叠行、“修改…”浮层） | `pages/shots/scan-C-*.png` |

## 目标 / 非目标 / 反目标

- 目标：四页布局按选定原型重排；原型里每个控件的位置与原型一致。
- 非目标：不改识别、扫描、交付、转写、设置读写等业务逻辑；不改配色体系；不动模板页。
- **反目标（验收硬线）**：任何现有功能丢失或变得不可达——按钮、输入、分段选择、开关、“?”说明、悬停说明、快捷键（如结果页 PgUp/PgDn、扫描页空格暂停/继续）、启用/禁用及其原因说明、空状态提示、双击行为、离开设置页的未保存询问等，一个都不能少。

## 各页要点

**考试页 B**：全宽考试表，点行原位展开，显示考试详情（科目代码、考场、操作员、创建时间、模板快照 ?）和批次子表；考试操作（打开考试目录、扫描新批次）在考试行尾，仅展开行用主按钮样式；批次操作（继续扫描、查看结果、打开目录）在批次行尾；“新建考试”在页顶，打开右侧抽屉，抽屉里是原新建表单和唯一主按钮“创建并进入扫描”；没有考试时“新建考试”为主按钮。原有双击行为保留。

**扫描页 C**：左栏管批次——批次名、状态、? 、“新批次”，物理异常列表（每张卡的全部处理按钮），已作废、数据警告折叠成可展开的行，底部“结束批次（结算）”及其前置检查清单（未处理异常数、是否正在识别、数据警告不拦截）。中栏保持：下一步提示、提示条、统计数字、批次进度拼图及图例、最近一张及读数，区域色码移到卡面下方一行。右栏管本轮——输入源、扫描仪选择/刷新、文件导入的配对说明与文件/文件夹选择、扫描参数收成一行摘要 +“修改…”弹出全部参数（进纸、DPI、色彩、双张检测、颜色滤除 ?、裁边 ?、600 DPI 提示）、模板、输出目录；底部开始识别/暂停/继续、结束本轮、空格键提示、“本轮和批次的区别 ?”。

**结果页 B**：顶栏批次名 + 刷新 +“核对答卷 / 交付（N 项阻断）”模式切换。核对模式：左栏学生（搜索、筛选、?）、中间卡面/证据 JSON、叠层说明、卡面下方悬浮条（上一份 / 第 k/n 份 / 下一份、正面 / 背面）、右栏客观题答案与信息栏/主观题（单项重试转写）。交付模式：整页清单——“先检查交付”（?、检查按钮、结论、阻断项及其处理按钮/去处、说明项）与“再生成交付目录”（不能点时写明原因）；右栏批次统计与转写统计，整批转写按钮（补做和重试转写、放弃未完成转写…、?）。“下一步”提示两种模式都显示。

**设置页 A**：顶部常驻条：页标题、说明、未保存提示（列出改了哪些项）、保存设置。左栏分节：输出（必设）、扫描默认参数（用扫描仪时）、大模型转写（可选）、区域色码（参考），每节显示当前取值摘要，改过的节标点；右侧一次显示一节，改过的字段标出并显示原值。base_url / api_key 改为中文主标签（接口地址 / 密钥），英文作小字副标签。默认打开“输出”。

## 实现约束

- 保留各页被其它模块和测试引用的属性名、方法名和信号；必须换掉的，同步改调用方和测试，且换成等价能力。
- 原型里新增的展示（如设置页节摘要和“原为…”、扫描页结算前检查清单、考试页展开区详情、结果页交付页统计）只用现有数据算出；算不出的不硬造，在报告里列出。
- 颜色只用 theme token，深浅两套主题都正确；最小窗口 1280×800 内不被截断。
- 每页：现有测试全部通过；新增测试覆盖新布局里每个控件可达、模式/展开/折叠/抽屉切换、关键状态（启用/禁用原因）。
